# Skills

Shared by every agent through `~/.agents/skills` (stowed from this package). The ponytail plugin covers code size, reuse, dependencies, `/ponytail-review`, and `/ponytail-audit`, so nothing here duplicates those.

| Skill | Fires | For |
|---|---|---|
| `typescript` | auto | type modeling, boundaries, escape hatches |
| `react` | auto | Effects, state ownership, memoization, component APIs, a11y |
| `comments` | auto | when a comment earns its place |
| `unslop` | auto | prose without AI tells |
| `git-workflow` | auto | never commit, commit-preparation summary |
| `diagnose` | auto | hard bugs and perf regressions |
| `tdd` | auto | test-first, agreed seams |
| `verify` | auto | proving work before calling it done |
| `grill` | auto | stress-testing a plan in rounds |
| `spec` | auto | spec file plus implementation brief |
| `prototype` | auto | throwaway UI variants or logic demos |
| `writing-for-agents` | auto | editing skills and AGENTS.md |
| `client-estimate` | auto | scoping and pricing client work |
| `my-voice` | auto | emails and copy sent as the user |
| `spec-review` | `/spec-review` | diff versus spec |
| `handoff` | `/handoff` | pass a session to a fresh agent |
| `correct` | `/correct` | turn repeated mistakes into checks |

Review a change with `/ponytail-review` for quality and `/spec-review` for scope.
